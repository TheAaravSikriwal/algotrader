# Strategy source material

Eleven pieces of strategy material the account owner collected — text lists,
AI-generated answers, and YouTube transcripts — transcribed into specification
files here.

These are **raw material, not analysis.** They were written to be faithful to
what each source said, including the parts that are wrong, unfalsifiable, or
sales copy. Quoted numbers are the source's claims, not verified facts. Where two
sources contradict each other the contradiction has been left in place.

Provenance of each file is stated in its first line. Monetisation, if any, is
noted, because it bears on how the claims should be read.
